# Ad Manager Bot

Telegram Mini App для управления рекламными кампаниями.

## Функции

- 👤 **Рекламодатели** — добавление ника/ссылки рекламодателя
- 🔗 **Промо-ссылки** — управление промо-материалами (ссылка + название)
- 📅 **Дедлайны** — установка дедлайнов для каждой задачи
- 📊 **Статусы** — Готово / Не готово / В процессе
- 📝 **Заметки** — текстовые заметки к каждому рекламодателю/задаче
- 🔔 **Уведомления** — напоминания о дедлайнах
- 💱 **Конвертер USDT/RUB** — поле цены с автоконвертацией по текущему курсу
- ⚙️ **Профиль** — статистика и управление аккаунтом

## Стек

- **Backend**: Python, FastAPI, aiosqlite
- **Frontend**: HTML/CSS/JS + Telegram WebApp SDK
- **Bot**: python-telegram-bot
- **Database**: SQLite

## Запуск

### 1. Установка зависимостей

```bash
pip install -e .
```

### 2. Настройка переменных окружения

```bash
export BOT_TOKEN="your-telegram-bot-token"
export WEBAPP_URL="https://your-domain.com"
```

### 3. Запуск API сервера

```bash
python run_api.py
```

### 4. Запуск бота

```bash
python run_bot.py
```

## Переменные окружения

| Переменная | Описание | По умолчанию |
|-----------|----------|-------------|
| `BOT_TOKEN` | Telegram Bot API token | — |
| `WEBAPP_URL` | URL мини-приложения | `https://localhost:8000` |
| `DB_PATH` | Путь к файлу базы данных | `data.db` |
